# FITLY – AI Fashion Stylist & Commerce Application

Fitly adalah aplikasi fashion commerce modern yang menggabungkan AI Personal Stylist, katalog produk fashion, digital wardrobe, dan virtual try-on shopping assistant untuk meningkatkan keyakinan belanja pengguna.

## Fitur Utama
1. **Discover & Catalog**: Kurasi busana terbaik, filter gaya multi-kategori, pencarian cerdas, dan rekomendasi cuaca.
2. **AI Personal Stylist**: 8 skenario acara (Campus, Office, Date, Travel, Hangout, Formal, Daily, Sporty) serta asisten chat "Ask Fitly".
3. **Digital Wardrobe**: Digitalisasi lemari pakaian dan fitur "Complete My Look" untuk mencocokkan pakaian milik pengguna dengan katalog belanja.
4. **Try With My Wardrobe**: Virtual Try-On shopping assistant untuk melihat keserasian produk baru dengan koleksi pakaian yang sudah dimiliki.
5. **Live AR Preview**: Pratinjau langsung kamera dengan deteksi siluet tubuh dan keypoints tracking.
6. **Full Commerce Flow**: Outfit bundle discounts, multi-seller cart, kupon voucher, pemilihan kurir pengiriman, simulasi pembayaran (E-Wallet, VA, Kartu), dan pelacakan pesanan real-time.

## Persyaratan:
1. Flutter SDK (>= 3.3.0)
2. Dart SDK (>= 3.3.0)
3. Android Studio / VS Code / Antigravity

## Menjalankan Aplikasi:
```bash
# 1. Ambil dependencies
flutter pub get

# 2. Jalankan aplikasi (Chrome / Emulator Android):
flutter run -d chrome
# atau untuk Android device:
flutter run

# 3. Jalankan automated tests:
flutter test
```
